# MaximumPixel 🎬✨

> **Official Website & Portfolio for MaximumPixel — Jaipur-Based Creative Content & Media Studio**

MaximumPixel is a modern creative media production studio based in Jaipur, Rajasthan, founded by **Krishna Rajak** (Founder & Creative Lead), **Vishwajeet Barman** (Co-Founder & Visual Lead), and **Rahul Gyanchandani** (Co-Founder & Strategist).

---

## 🚀 Key Features

- **Interactive 3D Mascot Experience**: Built with Three.js WebGL & GLTF cursor tracking.
- **Full Media Services Portfolio**: Commercial video, photography, social media reels, event coverage, product/property shoots, and visual branding.
- **Dynamic Content System**: SQLite database powered by Prisma ORM for client inquiries and messages.
- **Modern Tech Stack**: Next.js 14 App Router, TypeScript, Tailwind CSS, Framer Motion, and Nodemailer.
- **100% Responsive Design**: Optimized for smartphones, tablets, and high-DPI displays.
- **SEO & Social Engine Ready**: Complete JSON-LD structured schemas, dynamic OpenGraph metadata, XML sitemap, and robots.txt.

---

## 🛠️ Technology Stack

- **Framework**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Database & ORM**: [Prisma ORM](https://www.prisma.io/) with SQLite
- **Deployment**: [Vercel](https://vercel.com/)

---

## ⚡ Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Set up database
npx prisma generate
npx prisma db push

# 3. Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
