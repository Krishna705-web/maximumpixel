# Architectural & Design Decisions Log

This document records all explicit assumptions, design choices, and technical decisions made during development.

| ID | Topic | Decision | Rationale |
|---|---|---|---|
| DEC-001 | Framework | Next.js 14+ (App Router) + React + TypeScript + Tailwind CSS | Provides seamless server/client rendering, API routes, fast image optimization, and strict TypeScript types. |
| DEC-002 | Database Engine | SQLite via Prisma for local dev, Postgres-ready for production | Zero-config out-of-the-box local developer experience; easily swapped to PostgreSQL via `DATABASE_URL` in `.env.example`. |
| DEC-003 | Portfolio Filtering | Client-side reactive filter over structured project data with fallback GET API | Instant, snappy UI responsiveness with 0 latency for users, with an accompanying `/api/projects` endpoint available for external consumers. |
| DEC-004 | Email Handling | Nodemailer with graceful dev logging fallback | Ensures form works seamlessly even if SMTP credentials are not yet configured in local `.env`, while dispatching real emails once SMTP credentials are provided. |
| DEC-005 | Typography | `Archivo Black` / `Syne` for display headlines, `Inter` for clean body typography | Closely replicates the heavy grotesk uppercase look and readable body copy in the reference screenshots. |
| DEC-006 | Asset Placeholders & SVG Graphics | Inline vector SVGs for decorative confetti & corner bursts; native Next.js `<Image>` slots for mascots and logos | High performance, zero layout shift, and immediate drop-in replacement capability for future PNG/SVG assets. |
| DEC-007 | Responsive Strategy | Mobile-first baseline (375-430px) matching reference 1:1, expanding to 2-column on tablet (768px-1024px) and 3-column/side-by-side on desktop (1280px+) | Maintains visual weight without stretching mobile assets across wide screens. |
| DEC-008 | Brand Assets & Contact Data | Updated primary logo with user-provided high-res transparent faceted logo, updated phone (+91 78787 36798), email (hello.maximumpixel@gmail.com), and Co-Founder Rahul Gyanchandani | Accurate production contact information and official brand assets provided by user. |
| DEC-009 | Fluid Animations & Interactive Micro-UI | Implemented Framer Motion staggered hero text reveal, glowing process flow connector beam, layout animations on portfolio filtering, project lightbox modal, top scroll progress glow bar, and celebratory canvas-confetti on contact form submission | Significantly elevates interactive polish, micro-haptics, and engagement without altering core dark theme and visual identity. |
| DEC-010 | Advanced Conversion & Studio Features | Implemented Floating Sticky WhatsApp live chat, Interactive FAQ Accordion, Client Testimonials Slider, Trending Reels & Shorts 9:16 Showcase, Interactive Project Scope & Pricing Calculator (₹ INR with 1-click WhatsApp quote locking), Founder Admin Messages Dashboard (/admin/messages), and dynamic XML Sitemap + Robots.txt + JSON-LD LocalBusiness Schema | Transforms MaximumPixel into a high-converting, feature-complete studio platform with real-time lead capture, price transparency, and social proof. |
| DEC-011 | 3-Way Dynamic Theme Mode (Black, White, Night Vision) | Implemented ThemeProvider with localStorage persistence, zero-flash SSR initialization script, and interactive segmented toggle in Header & Footer for Black (Dark), White (Light Editorial), and Night Vision (Tactical CRT Emerald HUD) | Gives visitors full visual customization with instant smooth transitions across all pages. |
